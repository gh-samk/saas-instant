# i18n (apps/control)

Bezeichner im Code sind englisch, sichtbare Texte deutsch und liegen im Wörterbuch.

- Wörterbuch: `apps/control/src/i18n/locales/de/<namespace>.ts`, `export default { key: 'Text' }`.
  Ein Namespace je Seite/Komponentengruppe; der Dateiname ist der Namespace. `locales/index.ts`
  sammelt alle Dateien automatisch (`import.meta.glob`), nichts muss registriert werden.
- Zugriff: `const t = useT(); t('company.title')`, Platzhalter `t('x.hello', { name })` mit `{name}` im Text.
  Plural: Schlüssel `foo_one` / `foo_other` anlegen, `t('foo', { count })` wählt die Form.
  Unbekannte Schlüssel liefern den Schlüssel selbst.
- Sprache: `I18nProvider` (in `browser.tsx`) nimmt `localStorage` (`saas-instant.locale`), dann
  `navigator.language`, sonst `de`. Aktuell existiert nur `de`; weitere Sprachen = Ordner `locales/<xx>/`
  plus Eintrag in `dictionaries` (`locales/index.ts`).
- Prüfung: `src/i18n/key-check.test.ts` (vitest) sucht per Regex alle `t('…')`-Literale im Code und
  schlägt fehl, wenn ein Schlüssel im Wörterbuch fehlt. Dynamisch gebaute Schlüssel werden nicht erfasst.

Einschränkung v1: Backend-Meldungen und Mailtexte bleiben vorerst nur deutsch.
